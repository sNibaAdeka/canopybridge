# Реалистичные IE-1 и ринг — v1 (2026-10-02)

Источник: `Tools/Blender/Realistic/` (Blender 4.5 LTS, Cycles CPU, 1600×900, 96 сэмплов + OIDN).
Повтор: `python render_showcase.py --shots hero,game,forge,wide --res 1600x900 --samples 96 --outdir <папка>`
(Blender как модуль: `pip install bpy==4.5.*`, Python 3.11).

| Файл | Кадр |
|---|---|
| `hero.jpg` | крупный план: джеб Forge в защиту Ember |
| `game.jpg` | игровая камера из-за плеча игрока |
| `forge.jpg` | деталь: броня, номер, трафареты, винты, карбоновое предплечье Forge |
| `wide.jpg` | общий план арены |

Кадр `ember` отбракован: перчатка Forge входит в шлем Ember (позы без коллизий, см. ворота 5).

## Честные ограничения

- Модели построены кодом (без скульпта и фотограмметрии): уровень качественного hard-surface CG, не скан.
- Зрители — низкополигональные силуэты: читаются в темноте и размытии, вблизи — нет.
- Материалы процедурные (Cycles). Для Unreal их нужно **запечь** в BaseColor/Normal/ORM — следующий шаг после одобрения вида.
- В Unreal ничего не импортировалось и не проверялось (нет Windows-ПК в облаке).
