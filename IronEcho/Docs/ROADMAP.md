# ROADMAP — до уровня «как UFC»

Ориентир — ощущение и подача серии EA UFC, но в формате бокса роботов с управлением телом через камеру.
Честно: AAA-объём (десятки бойцов, мокап, комментаторы) командой из двух агентов и одного автора не повторить.
Повторяем **то, что делает бой «как UFC»**: вес удара, глубину защиты и выносливости, нокдауны и судей,
телевизионную подачу, ИИ со стилями. Каждый этап проверяется людьми (`Docs/Testing/HUMAN_TRIALS.md`).

## Что значит «уровень UFC» для нас

| Столп | Признак готовности | Кто |
|---|---|---|
| Вес удара | попадание читается без HUD: реакция головы, хит-стоп, искры, звук, тряска камеры | Codex (визуал), Claude (данные событий, тайминги) |
| Глубина боя | смысл есть у каждого действия: джеб/кросс/связки, блок/уклон/контратака, выносливость, нокдауны, судьи | Claude |
| Честность управления | удар игрока засчитан ≥ 95 %, ложных < 1 на раунд, задержка ≤ 150 мс | Claude + испытания Адёки |
| ТВ-подача | выход бойцов, табло раунда, карточки судей, статистика между раундами, повтор нокаута | Codex (вид), Claude (данные, буфер повтора) |
| Соперники | 3 робота со стилями (контрпанчер, давящий, аутбоксер), читаемый телеграф | Claude (ИИ; модели IE-1 — решение автора 2026-10-02), Codex (анимации) |
| Стабильность | 60 fps на i5-12400F + RTX 3050, запуск без Python/Unreal, понятные ошибки камеры | Claude (техника), Codex (бюджет графики) |

сейчас, потому что не требуют новых жестов и проверяются тестами без камеры.

## Разделение работы (без пересечений)

**Claude — техника и геймплей**
- правила боя, баланс, ИИ и его стили, нокдауны/судьи/статистика, новые удары (после M1);
- трекер: распознавание новых жестов, калибровка, задержка, запись испытаний → регрессионные тесты;
- данные для подачи: события, буфер повтора последних секунд (позы/события), статистика раунда;
- Unreal: GameMode, Config, интеграция контента Codex по контрактам, сборка, упаковка, тесты;
- (решение автора 2026-10-02) реалистичные роботы IE-1 и ринг/арена: `Tools/Blender/Realistic/`, `Docs/Visual/REALISM_BRIEF.md`.

**Codex — видимое, кроме моделей роботов и ринга**
- анимации ударов/защиты/реакций/нокдаунов/подъёма (на скелете контракта §4);
- VFX попаданий, хит-стоп и тряска камеры (визуально, без изменения правил);
- камера боя и камера повтора, ТВ-графика: табло, карточки судей, статистика, меню;
- бюджет графики под измеренную VRAM.

**Адёка — автор и тестировщик**
- испытания перед камерой по сценариям (5–10 минут), ощущения: честность, задержка, усталость;
- решения по вкусу и объёму: стиль роботов, названия, что идёт в следующий этап.

**Правило против дублирования:** любая задача из этого файла имеет одного владельца. Пересечение (например, хит-стоп)
делится так: данные и тайминги — Claude, вид — Codex. Новые общие поля — только через контракт и handoff.
