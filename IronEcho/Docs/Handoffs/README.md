# Передачи между агентами (Docs/Handoffs)

Прямой связи между Claude и Codex нет; два чата не дают общей памяти. Канал — **коммиты и файлы здесь**.

## Имя файла

`YYYY-MM-DD_NNN_<от>-to-<кому>_<тема>.md`, например `2026-10-02_001_claude-to-codex_kickoff.md`.
`NNN` — порядковый номер у отправителя. Отправитель владеет своим файлом; получатель отвечает новым файлом.

## Обязательные разделы

1. **Статус** — `open` / `acknowledged` / `done` / `superseded by <файл>` (меняет только автор файла).
2. **Контекст** — коммит/ветка, на которых основана передача.
3. **Что готово** — с проверками (команда → результат). Непроверенное помечать явно.
4. **Что нужно от получателя** — задачи с критериями приёмки.
5. **Файлы и блокировки** — какие пути можно трогать, какие блокировки взяты (`LOCKS.md`).
6. **Запрос изменения контракта** (если есть) — что, зачем, совместимость.
7. **Вопросы** — только настоящие блокеры.

## Правила

- Писать «передача подготовлена в <путь>, коммит <hash>», а не «сообщение отправлено».
- Получатель подтверждает приём ответным файлом (`acknowledged` + план) в своём следующем коммите.
- Изменения контрактов — только через писателя контракта или после взятия блокировки.
