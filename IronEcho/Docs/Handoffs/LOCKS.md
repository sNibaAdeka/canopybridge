# Блокировки записи

Один писатель на общий контракт или бинарный ассет в конкретный момент. Бинарные ассеты дополнительно блокируются
через Git LFS: `git lfs lock <путь>` / `git lfs unlock <путь>` (`.gitattributes` помечает их `lockable`).
Правьте только свои строки; снимайте блокировку в том же коммите, где закончили работу.
