# 009 Claude → Codex: ринг, ноги и точные удары (контракт визуала 2.0)

**Статус:** open. Для Unreal-графики это **MAJOR** (`ROBOT_VISUAL_CONTRACT.md` 2.0): бойцы больше не на одной линии.

## Что изменилось в данных

| Было (1.1) | Стало (2.0) |
|---|---|
| актор бойца ставился в точку на линии X, поворот 0°/180° | `SlotTransform` = позиция на холсте (X и Y) + поворот лицом к сопернику; бойцы ходят, кружат, прижимаются к канатам |
| `DistanceToOpponent` вдоль линии | расстояние между центрами по холсту |
| нет скоростей | `FIronEchoFighterVisualState`: `MoveForwardSpeed`, `MoveRightSpeed` (см/с, для цикла ног), `bOnRopes` |
| голова двигалась только позой | `HeadSlip` — реальный сдвиг головы вправо (см). По нему считаются промахи: рисуй голову там же |
| один тип удара | `bBodyShot` у текущей атаки; события `HitConfirmed`/`Blocked`: `bBodyShot`, `bGlancing`, `bSmothered`, `Power` |
| `AIronEchoRingAnchor::UsableHalfLength` — длина линии | предел центра бойца по X **и** Y (квадрат); 260 см даёт ринг 5.9 м между канатами |

## Что нужно от графики

1. **Ноги.** Актор уже идёт и поворачивается сам; AnimBP должен крутить цикл шага по `MoveForwardSpeed/MoveRightSpeed`
   (шаг вперёд/назад, боковой приставной шаг при кружении). `bOnRopes`: откинуться на канаты, руки выше.
2. **Корпус.** `bBodyShot` на атаке: удар идёт на уровень рёбер, присед и наклон корпуса; реакция получателя на `HitConfirmed`
   с `bBodyShot` — складывается вперёд, голова остаётся на месте.
3. **Вскользь / вплотную.** `bGlancing` — лёгкая реакция (мотай `Power`); `bSmothered` — короткий вязкий удар, без размаха.
4. **Камера.** Если `GameCameraClass` из `DA_IronEchoVisuals` задан — она должна следовать за линией боя (бойцы
   вращаются вокруг центра). Без неё `AIronEchoGameMode::UpdateFallbackCamera` ведёт запасную камеру за правым плечом игрока.
5. **Карта арены.** Свободная зона теперь квадрат ±(`UsableHalfLength` + 40) см по обеим осям — проверь, что канаты и ограждение не пересекают её.

## Ввод (для меню/подсказок HUD)

Клавиатура: W/S шаг, A/D круг, J/K удары в голову, Shift+J/K или N/M в корпус, Q/E уклон (было A/D), Пробел блок.
Камера: наклон к экрану — шаг вперёд, от экрана — назад (подсказку в калибровке я добавил в веб; в Unreal HUD — на тебе).

Источник правды: `INPUT_CONTRACT.md` 1.3, §9a. Эталон реализации в вебе: `Tools/Build/Web/site/src/anim.js` (ноги по скоростям,
удар идёт к `aimX/aimY`, корпус) и `main.js` (`updateStage`).

Не проверено: Unreal-сторона целиком (нет Windows/Unreal в облаке); C++-модуль игры правился без компиляции Unreal.
Сообщение создано как файл передачи; доставка — через общий репозиторий.

## Дополнение (контракт визуала 2.1): удары ногами

Автор добавил в игру удары ногами. Данные: `bKick` / `bLowKick` у состояния бойца и у событий, `LegSlowSeconds`.
`AttackHand` для ноги: Left — передняя (быстрый прямой «теп», досягаемость 1.72 м), Right — задняя (круговой, 4.0 урона).
Что нужно от графики: замах — колено вверх и назад (у бота 0.5–0.9 с, это телеграф), удар — нога по прямой (теп) или по
дуге через бедро (круговой), при `bLowKick` — низкая траектория на уровне голени; стоячая нога держит вес, корпус
откидывается; после удара без отмены (на одной ноге, ~0.5 с). Получатель: удар в корпус — складывается; по ногам —
подсекается колено, хромота пока `LegSlowSeconds > 0`. Эталон — `Tools/Build/Web/site/src/anim.js` (`kickPose`, `_applyKick`).
