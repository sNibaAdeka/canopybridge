# Испытания с человеком перед камерой

Отладочная клавиатура и синтетика **не заменяют** эти испытания. Каждый прогон — с записью
(`--record`), чтобы пороги настраивались на реальных данных и превращались в регрессионные тесты.

**Подготовка (один раз):** камера на уровне груди, 2.5–3 м до игрока, игрок виден по колени, свет спереди,
однотонный фон по возможности. Запуск — команды ниже (их выполняет Claude в локальной сессии на ПК или скрипт).

## T1. Трекер без игры (5 мин)

`Tracking\.venv\Scripts\python -m iron_echo_tracker run --preview --calibrate full --record Saved\Trials\t1.jsonl`

1. Встаньте в стойку 5 с. Ожидание: `TRACKING`, `conf` ≥ 0.8, `lean` около 0.
2. Сразу после запуска идёт полная калибровка (4 шага, подсказки в окне). Ожидание: `calib VALID DONE`; на шаге
   «правая рука» поднимайте именно правую.
3. 10 джебов левой, пауза, 10 кроссов правой. Ожидание: каждый удар — одна надпись `PUNCH LEFT/RIGHT`, без двойных.
4. Блок (перчатки ко лбу) 3 с, затем уклоны влево/вправо по 3 раза. Ожидание: `block` > 0.6 в блоке; `lean` < −0.6 и > +0.6;
   **ни одного** ложного `PUNCH`.
5. Опустите руки, отойдите из кадра и вернитесь. Ожидание: `NO_PERSON`, затем снова `TRACKING`.

Сообщить: сколько ударов пропущено / лишних; заметна ли задержка; файл `t1.jsonl`.

## T2. Груша в игре (5 мин)

Запуск игры (режим по умолчанию — тренировка). F3 — теховерлей.
1. Статус `Live`, затем отсчёт. 2. 20 ударов чередуя руки. Ожидание: робот бьёт той же рукой, груша качается,
   счётчик `Confirmed bag hits` растёт на каждый удар. 3. Блок и уклоны: робот повторяет корпус и руки.

Сообщить: процент засчитанных ударов, ощущение задержки (нет / терпимо / мешает), FPS из теховерлея.

## T3. Бой с ботом (10 мин)

F2 → бой (1/2/3 — сложность). Ожидание: отсчёт, 3 раунда, бот бьёт с видимым замахом, от удара бота можно уйти
реальным уклоном или блоком, итог KO/решение, Enter — реванш.

## T4. Потеря трекинга и пауза (3 мин)

Во время раунда выйдите из кадра на 3 с. Ожидание: пауза «потеря трекинга» через ~0.5 с, таймер стоит; вернитесь —
через ~1 с отсчёт 3-2-1 и продолжение с того же времени. P — ручная пауза и возобновление.

## T5. Зеркальная камера (если в драйвере есть отражение, 2 мин)

Включите отражение в настройках камеры, пройдите полную калибровку. Ожидание: `mirror=True`, левый удар — по-прежнему левый.
