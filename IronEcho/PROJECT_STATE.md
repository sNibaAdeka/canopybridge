Обновлено: 2026-10-04, Claude (облачная Linux-сессия). Владелец файла — Claude; Codex сообщает через `Docs/Handoffs`.

## Одобренный объём v1

Windows x64, одна камера, готовый MediaPipe; левый и правый прямой, блок, два уклона; один ринг, один бот;
законченные раунды и результат; робот постоянно повторяет стойку и уклоны, удары — игровая обработка;
автоматическая дистанция. После базовой приёмки: онлайн, хуки, апперкоты, две камеры.

План до «уровня UFC» и разделение работы: `Docs/ROADMAP.md`.

## Играть сейчас: браузерная версия (2026-10-04)

Пока Unreal не собран на ПК, играбельный бой — в браузере (`Tools/Build/Web/README.md`): **то же C++-ядро правил**
в WebAssembly (бит-в-бит с нативной сборкой), реалистичные IE-1 (72 тыс. треугольников, запечённые 2K-текстуры), ринг по
размерам `ring.py`, зал — панорама Cycles, процедурная анимация (порт `robot.pose()`), HUD, звук, бот трёх уровней.
Управление: клавиатура/мышь/сенсор; **камера** — в самодостаточном файле `IronEcho-Camera.html` (порт трекера совпадает с
Python-трекером бит-в-бит по ударам). Ссылка — приватный артефакт claude.ai (камера там запрещена песочницей).
Не проверено: FPS на реальной видеокарте, камера с живым человеком.

## Настоящий блокер

Всё дальнейшее требует **Windows-ПК автора** (Unreal, камера, GPU). Из облака туда не дотянуться. Нужно одно из двух:
1. (рекомендовано) открыть этот репозиторий в Claude Code на Windows-ПК (desktop-приложение или CLI) — локальная сессия
   сама выполнит `Tools/Build/Bootstrap-Windows.ps1`, сборку, пробник, тесты и упаковку;
2. или один раз выполнить `powershell -ExecutionPolicy Bypass -File Tools\Build\Bootstrap-Windows.ps1` из папки `IronEcho`
   и закоммитить `Docs/Reports/<дата>_env_windows.md`.

Предусловия на ПК: Unreal Engine 5.x (Epic Launcher), Visual Studio 2022 с «Game development with C++», Python 3.12, Git LFS.
Bootstrap сам скажет, чего не хватает.

## Риски

- Unreal-слой не компилировался: возможны мелкие ошибки API под конкретную версию движка — правятся при первой сборке.
- Пороги жестов настроены на синтетике; реальные данные (особенно глубина запястья у MediaPipe) потребуют подстройки.
- Размер трекера (439 МБ на Linux) — оптимизация после работоспособности.
- Квота Git LFS GitHub для арта Codex.
- **Баланс (исправлено 2026-10-04, правила 1.2):** было — 100 % боёв нокаутом в 1-м раунде, «молотилка» выигрывала всё;
  стало — бои доходят до 3-го раунда, 20 % решений судей у среднего игрока против Normal, молотилка проигрывает
  (`Docs/Reports/2026-10-04_balance/`). Модель игрока синтетическая — подтверждать на людях.
- Исходные `robot-boxing-master-prompt.md` и `robot-boxing-team-plan.md` не найдены; работа ведётся по стартовому промпту.
  Если файлы появятся — сверить контракты и владение.

- `Tests/Tools` — 6 тестов валидатора робота (`Tools/Unreal/Tech/validate_robot.py`).
- Две рабочие копии: Claude — `sNibaAdeka/canopybridge` (`IronEcho/`), Codex — `sNibaAdeka/iron-echo` (у Claude нет доступа).
  Пока не сведены в одну, интеграция графики Codex в Unreal-проект невозможна.
