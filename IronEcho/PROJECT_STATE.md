# PROJECT_STATE — IRON ECHO

Обновлено: 2026-10-06, Claude (облачная Linux-сессия). Владелец файла — Claude; Codex сообщает через `Docs/Handoffs`.

## Одобренный объём v1

Windows x64, одна камера, готовый MediaPipe; левый и правый прямой, блок, два уклона; один ринг, один бот;
законченные раунды и результат; робот постоянно повторяет стойку и уклоны, удары — игровая обработка;
автоматическая дистанция. После базовой приёмки: онлайн, хуки, апперкоты, две камеры.

План до «уровня UFC» и разделение работы: `Docs/ROADMAP.md`.

## Не проверено

Компиляция и запуск Unreal-модуля; редакторский Python; реальная камера и человек; задержка «движение → удар робота»;
FPS и VRAM на целевом ПК; упаковка игры; трекер под Windows; баланс боя на людях.

## Настоящий блокер

Всё дальнейшее требует **Windows-ПК автора** (Unreal, камера, GPU). Из облака туда не дотянуться. Нужно одно из двух:
1. (рекомендовано) открыть этот репозиторий в Claude Code на Windows-ПК (desktop-приложение или CLI) — локальная сессия
   сама выполнит `Tools/Build/Bootstrap-Windows.ps1`, сборку, пробник, тесты и упаковку;
2. или один раз выполнить `powershell -ExecutionPolicy Bypass -File Tools\Build\Bootstrap-Windows.ps1` из папки `IronEcho`
   и закоммитить `Docs/Reports/<дата>_env_windows.md`.

Предусловия на ПК: Unreal Engine 5.x (Epic Launcher), Visual Studio 2022 с «Game development with C++», Python 3.12, Git LFS.
Bootstrap сам скажет, чего не хватает.

## Решения

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-02 | Проект в `IronEcho/` внутри репозитория CanopyBridge | назначенная ветка этого репозитория; архив CanopyBridge не тронут; при желании выносится `git subtree split --prefix IronEcho` |
| 2026-10-02 | Правила/протокол — чистый C++20 модуль `IronEchoRules` | тестируется без Unreal, тот же код в игре |
| 2026-10-02 | Трекер — отдельный процесс Python + PyInstaller; распознавание жестов в трекере | проверяется без игры (`--preview`), запись/воспроизведение для настройки порогов |
| 2026-10-02 | MediaPipe 1.0.1 Tasks API, модель full по умолчанию | `mp.solutions` удалён в 1.0; full ≈ lite по скорости на CPU, точнее |
