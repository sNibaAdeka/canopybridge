# Оценка камеры на реальных записях

- `eval_camera.mjs` — файлы режима «Помочь улучшить камеру» (`?collect=1`, `ironecho-session-*.json.gz`) прогоняются через те же детекторы, что в игре
  (`site/src/pose.js`), от собственной калибровки файла. Итог: таблица «удар × условие (A/B/C)»: попал, вид верный (рука и удар верные, цель нет),
  перепутал, пропуск, задержка от команды и от начала движения; ложные срабатывания в спокойных блоках в минуту.
  `node Tools/Build/Eval/eval_camera.mjs <файлы или папка> --md Docs/Testing/CAMERA_ACCURACY.md --json Build/eval.json`
- `latency_from_video.py` — задержка «движение → вспышка» по видео с телефона (игра с `?latency=1`). `--selftest` проверяет сам анализатор.

Записи людей в репозиторий не кладутся (только числа скелета, но всё равно — с согласия и по отдельному решению). Подробно: `Docs/MasterPrompt/04_REAL_DATA_PROGRAM.md`.
